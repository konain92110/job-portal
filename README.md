# JobFinder - React Job Portal

A beginner-friendly ReactJS job portal assignment using:
- ReactJS
- JavaScript ES6+
- HTML5 & CSS3
- Bootstrap 5
- REST API integration
- React Hooks: useState, useEffect, useContext
- React Router
- Git/GitHub

## API
This project uses the free Arbeitnow Job Board API:
https://www.arbeitnow.com/api/job-board-api

The API does not require an API key.

## Run the project

1. Install Node.js (LTS).
2. Open this project folder in VS Code.
3. Open the VS Code terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite.

## Build for deployment

```bash
npm run build
```

The production files are generated in the `dist` folder.

## Features

- Fetch jobs from REST API
- Search jobs
- Filter by job type, location and category
- Pagination
- Job detail page
- Save jobs using React Context + localStorage
- Application form with validation
- Loading, error and empty states
- Responsive Bootstrap layout
- React Router multiple pages
